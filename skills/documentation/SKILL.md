# Documentation

## 表記規則

ドキュメントを記述する際は、以下の表記規則に従う。

- ファイル名は英語のkebab-caseで命名する。
- 見出しには番号を付与しない。
- 区切り線は利用しない。
- 太字の使用は必要最低限に抑える。
- コードブロックでシェルコマンドを扱う際は、bashではなくshellを利用する。
- 表を利用する場合、ヘッダーの区切り線は各列ともハイフンもしくはコロン3つの組み合わせとする。
  - 例： `---` , `:--` , `:-:` など。
