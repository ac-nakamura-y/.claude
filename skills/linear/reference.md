# Reference

Issue の description テンプレートと、作成結果の報告形式を示す。

## Description Templates

単体タスク向けの description は次の構成とする。

```markdown
## 背景・目的
...

## スコープ
...

## 完了条件
...

## 参考
- <url>
```

マイルストーンや分割タスク向けの description は次の構成とする。

```markdown
## 背景・目的
...

## インプット
- ...

## アウトプット
- ...

## スコープ外
- ...

## 前提
- ...

## 関連Issue
- MRTTOPS-xxxx
```
